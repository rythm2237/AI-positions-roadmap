# CV document fonts

Ten open-source families for Arabic-script (Persian, Arabic, Urdu) and Devanagari resumes, each with regular (400) and bold (700) static TTF files. Sources are official Google Fonts repositories, recorded in sources.json. Each family includes its original SIL Open Font License (OFL.txt). Fonts incur no per-use licensing fee; translation still uses the site's existing AI allowance.

Variable sources were instantiated at weights 400 and 700 with fontTools varLib.instancer; all glyphs were retained. Static families use the upstream regular/bold files. These licensed, checked-in assets are copied to public/application-studio/fonts during the normal application-studio build. Builds do not fetch fonts from external services. Browser previews, downloadable HTML and PDF use the same selected family.
